## 2.0 为什么需要"传输线理论"？（零基础直觉入门）

在普通电路课里，你学的是"集总参数电路"：一根导线只是把两个元件连起来，
导线本身**没有电阻、没有延迟**，电压在导线两端处处相等。这是因为低频时
信号的波长远大于电路尺寸（比如50Hz电源信号波长约6000公里，你家的电线
才几米长，可以认为电压"瞬间"传遍全程）。

但RF信号频率非常高（几百MHz到几十GHz），波长可能只有几厘米到几十厘米，
**跟电路板、电缆的物理尺寸差不多量级**。这时候导线不再是"理想的一根线"，
而要看成一条有长度的"传输通道"——信号沿着它传播需要时间，不同位置的
电压、电流在某一时刻可能完全不同（就像水波在长水管里传播，不同位置
水面高度不同）。

**类比理解**：
- 想象一根很长的水管，一头突然推一下水（相当于加电压脉冲），这个"推力"
  不会瞬间传到水管另一头，而是像波一样**沿水管传播**，这就是电压/电流波
  沿传输线传播的直觉图像。
- 如果水管末端是"开口"（相当于开路）或者"堵死"（相当于短路），水波传到
  末端会**反弹**（反射）；如果末端接了一个和水管"完全匹配"的出水口，水波
  会顺畅流出、不反弹——这就是"阻抗匹配"最朴素的图像，也是本模块的核心。

本模块要解决4件事：
1. 描述"波沿传输线传播"的数学工具（传输线方程、特性阻抗Z0）
2. 描述"波遇到负载后反弹多少"的量（反射系数Γ）
3. 描述"从传输线输入端看进去，等效阻抗是多少"（输入阻抗Z_in，会随线长和位置变化！这和低频电路完全不同）
4. 一个把以上所有计算都图形化、几何化的神器——**Smith圆图**

## 2.1 传输线方程与特性阻抗Z0

### 2.1.1 分布参数模型
一根传输线（同轴线、微带线等）不能只看成一根理想导线，而要看成由
无数个"微小电路单元"首尾相连组成，每个微小单元包含：

```
   R'dz      L'dz
 o--/\/\/\--UUUU-----o
 |                     |
(信号线)          G'dz ═╪═ C'dz     （单位长度参数×微小长度dz）
 |                     |
 o---------------------o
   (地/回流路径)
```

- **R'**：单位长度串联电阻（导体本身的电阻损耗，Ω/m）
- **L'**：单位长度串联电感（电流流过导线产生的磁场储能，H/m）
- **G'**：单位长度并联电导（介质漏电损耗，S/m，通常很小可忽略）
- **C'**：单位长度并联电容（信号线和地之间的电场储能，F/m）

把很多个这样的微小单元串起来，就构成了整条传输线的模型，这叫
**电报方程（Telegrapher's Equations）**。求解这组方程，电压和电流的解是
"沿+z方向传播的正向波" 加上 "沿-z方向传播的反向（反射）波" 的叠加：

```
V(z) = V+ e^(-γz) + V- e^(+γz)     ← 电压 = 入射波 + 反射波
I(z) = (V+/Z0) e^(-γz) - (V-/Z0) e^(+γz)
```

其中：
- **γ = α + jβ** 称为传播常数：
  - α（衰减常数）：波每传播单位距离，幅度衰减多少（无损线 α=0）
  - β（相位常数）：波每传播单位距离，相位转过多少弧度，β = 2π/λ（λ是该传输线内的波长，不是自由空间波长）
- **特性阻抗 Z0 = √[(R'+jωL')/(G'+jωC')]**：无损线（R'=G'=0，本课程绝大多数题目都假设无损）时化简为
  **Z0 = √(L'/C')**

### 2.1.2 特性阻抗Z0到底是什么？（直觉理解）
新手最容易困惑的地方：Z0 **不是**"传输线本身消耗掉多少功率的电阻"（无损线
Z0是纯实数，但线是无损的，不消耗功率！）。Z0 描述的是：**在这条线上，
单独一个"行进中的电压波"和"跟随它的电流波"之间固定的比值**：

```
V+/I+ = Z0     （只要是同一个方向传播的波，电压比电流永远等于Z0）
```

类比：水管的"特性阻抗"可以理解成水管的粗细/材质决定的"波动阻力"——
和水管里到底有没有在流水、流多少水（负载情况）无关，只由水管本身
的物理结构（R'、L'、G'、C'，也就是横截面尺寸、材料）决定。
常见值：同轴电缆 50Ω 或 75Ω，微带线可通过改变线宽调整（Module 2讲义
及Module 5都会用到）。

## 2.2 反射系数 Γ（本模块最核心的概念）

### 2.2.1 为什么会有反射？
把传输线想象成信号的"高速公路"，Z0是这条路本身的"通行阻抗"。当波传到
终点，遇到负载阻抗 Z_L：
- 如果 **Z_L = Z0**：负载和线的阻抗完全一致，就像高速公路直接无缝对接到
  另一条完全相同的路，车流（信号功率）**畅通无阻地全部流入负载**，没有反射。
- 如果 **Z_L ≠ Z0**：阻抗不连续（像道路突然变窄或变宽），一部分能量必须
  "掉头往回走"——这就是反射波。

### 2.2.2 反射系数的定义与公式
在终端负载 Z_L 处，反射系数定义为"反射波电压"与"入射波电压"之比：

```
Γ_L = V-/V+ = (Z_L - Z0) / (Z_L + Z0)
```

**几种极端情况直觉验证**（强烈建议动手代入一遍，考试常直接问这些）：

| 负载情况 | Z_L | Γ_L | 物理含义 |
|---|---|---|---|
| 完全匹配 | Z_L = Z0 | Γ_L = 0 | 无反射，全部功率进入负载 |
| 短路 | Z_L = 0 | Γ_L = (0-Z0)/(0+Z0) = **-1** | 全反射，反射波与入射波幅度相等、相位相反（电压在短路点必须为0，靠反相抵消） |
| 开路 | Z_L = ∞ | Γ_L → **+1** | 全反射，反射波与入射波同相叠加（开路点电流必须为0，电压加倍） |
| 纯电阻，大于Z0 | 例：Z_L=100Ω, Z0=50Ω | 0 < Γ_L < 1（实数） | 部分反射，相位不变 |
| 纯电阻，小于Z0 | 例：Z_L=25Ω, Z0=50Ω | -1 < Γ_L < 0（实数） | 部分反射，相位翻转180° |
| 复数负载 | Z_L=R+jX | Γ_L是复数 | 既有幅度也有相位偏移，需要用复数运算（见例题2） |

**反射系数是复数**，因此有三种表达方式（呼应前面自测题第3题）：
1. 阻抗形式：Γ = (Z_L−Z0)/(Z_L+Z0)
2. 极坐标：Γ = |Γ|∠θ
3. 直角坐标：Γ = Γᵣ + jΓᵢ

### 2.2.3 沿线移动时反射系数如何变化？（"360°=半波长"的由来）
在距负载 d 处（无损线），反射系数为：

```
Γ(d) = Γ_L · e^(-j2βd)
```

**为什么指数上有系数"2"？** —— 因为Γ描述的是"入射波"与"反射波"的**相对相位差**：
- 入射波从某观察点走到负载，要走相位 βd
- 反射波从负载走回同一观察点，又要走相位 βd
- 两者相对相位差 = 去 + 回 = **2βd**（就像声音撞墙反弹回来，回声路程是去+回，单程的2倍）

代入 d=λ/2：2βd = 2×(2π/λ)×(λ/2) = 2π = **360°**。

**结论（务必记住）**：
- 沿线移动 **λ/4** → Γ在圆图上转 **180°**
- 沿线移动 **λ/2** → Γ在圆图上转 **360°**（转完整一圈，回到原来的Γ值，
  也就是说**阻抗每隔λ/2就会重复一次**）
- 移动方向：**从负载往信号源方向移动（d增大）** → 相位 e^(-j2βd) 的角度**减小**，
  对应Smith圆图上**顺时针**转动，这也是"顺时针=朝向发生器"这条规则的数学根源

## 2.3 输入阻抗公式（这是"传输线"和"普通导线"最大的不同！）

在普通电路里，无论导线多长，两端阻抗看起来都一样。但在传输线上，
**从不同位置往负载方向看进去，测到的"输入阻抗"是不同的**——因为不同位置
入射波和反射波叠加的比例不同。距负载 d 处的输入阻抗：

```
Z_in(d) = Z0 · [Z_L + jZ0·tan(βd)] / [Z0 + jZ_L·tan(βd)]
```

这个公式不需要死记硬背推导过程（由Γ(d)和V(z)/I(z)代数变换得到），
但**必须记住下面5个特殊情形**，因为几乎每次考试都会考：

| 终端情形 | 输入阻抗 Z_in(d) | 直觉记忆 |
|---|---|---|
| 短路 Z_L=0，d<λ/4 | Z_in = **jZ0·tan(βd)** → 正电抗（**感性**） | 短截线像个电感 |
| 开路 Z_L=∞，d<λ/4 | Z_in = **-jZ0·cot(βd)** → 负电抗（**容性**） | 开路短截线像个电容 |
| 匹配 Z_L=Z0 | Z_in = Z0（与d无关！） | 无论多长，看进去都一样，因为没有反射波 |
| d=λ/4（四分之一波长变换器） | **Z_in = Z0²/Z_L** | "大变小、小变大"的阻抗反演器，Module 3会大量用到 |
| d=λ/2 | Z_in = Z_L | 阻抗每半波长完全重复一次 |

**为什么短路/开路短截线能当电感/电容用？** 这是微波电路里非常重要的技巧
（Module 3的短截线匹配、Module 6的振荡器谐振电路都会用到）：因为一段
特定长度、终端短路或开路的传输线，其输入阻抗是纯电抗（纯虚数，不消耗
功率——因为终端是理想短路/开路，无损线上没有能量损耗），随长度变化可以
连续调节从0到±∞，等效于一个"可调电感/电容"，比真实的分立电感电容在
高频下更容易做、寄生效应更小。

## 2.4 驻波比 VSWR（Voltage Standing Wave Ratio）

### 2.4.1 什么是"驻波"？
当入射波和反射波在传输线上同时存在并叠加时，某些位置两者**同相相加**
（电压变大，称为"波腹" voltage maximum），另一些位置**反相相消**（电压
变小，称为"波节" voltage minimum），而且这些最大最小值的位置**固定不动**
（不随时间移动），像"驻扎"在原地一样，所以叫驻波。

沿线电压幅度分布大致如下（示意）：
```
|V(z)|
 Vmax  ⌒        ⌒        ⌒     ← 波腹（入射+反射同相）
       \      /  \      /
        \    /    \    /
 Vmin    ⌣            ⌣        ← 波节（入射+反射反相）
        └──λ/4──┴──λ/4──┘
```
（波腹和波节每隔 λ/4 交替出现一次，每隔 λ/2 重复相同的模式）

### 2.4.2 定义与公式
```
VSWR = Vmax / Vmin = (1+|Γ|) / (1-|Γ|)
反过来：|Γ| = (VSWR-1) / (VSWR+1)
```

| 情况 | \|Γ\| | VSWR |
|---|---|---|
| 完全匹配 | 0 | **1**（Vmax=Vmin，无起伏，理想情况） |
| 部分失配 | 0~1之间 | 1~∞之间 |
| 短路/开路（全反射） | 1 | **∞** |

**为什么工程师关心VSWR？**
1. VSWR过高说明大量功率被反射回信号源，**浪费功率**、降低系统效率
2. 波腹处电压远高于平均值，**可能超过器件耐压、损坏功放**
3. VSWR是现场用驻波仪/网络分析仪就能直接测量的量（不需要知道具体相位），
   所以是早期射频工程最常用的"匹配好坏"指标（现代更常用回波损耗RL，
   两者可互相换算，见Module 7）

## 2.5 Smith圆图（本课程贯穿始终的"图形计算器"）

### 2.5.1 为什么要发明Smith圆图？
反射系数Γ和阻抗Z之间的关系 Γ=(Z/Z0-1)/(Z/Z0+1) 是一个复数的**分式变换**，
直接用代数计算又慢又容易出错（例题2、3你已经体会到复数除法多繁琐）。
1939年Phillip Smith发明了一种图形工具：把复杂的复数除法运算，变成
**在图上画圆、找交点、读数字**——只要知道映射规则，很多计算几秒钟就能
在图上完成，这就是Smith圆图存在的意义。

### 2.5.2 圆图是怎么"画出来"的？（不需要你自己推导，但要理解原理）
1. 先把阻抗**归一化**：z = Z/Z0 = r + jx（r电阻部分，x电抗部分，都除以Z0变成无量纲数）
2. 双线性变换：Γ = (z-1)/(z+1)，可以证明——
   - **所有"r=常数"的直线**，在Γ平面上都变成了一个个**圆**（等电阻圆，都过Γ=1这一点，
     r=0的圆就是最外面的单位圆本身，r=∞收缩成一个点）
   - **所有"x=常数"的直线**，也都变成了一个个**圆弧**（等电抗圆弧，也都过Γ=1这一点，
     上半部分是x>0感性，下半部分是x<0容性）
3. 这些等r圆和等x圆弧交织在一起，就组成了我们看到的Smith圆图网格。
   **任何一个阻抗z，都对应圆图上唯一一个点**（等r圆和等x圆弧的交点）。

### 2.5.3 必须记住的圆图规则（读图/画图的"操作手册"）
1. **圆图中心** = 匹配点（Γ=0，z=1，即z=Z0，无反射）
2. **圆图最右点**（实轴上Γ=+1处） = 开路（z=∞）
3. **圆图最左点**（实轴上Γ=-1处） = 短路（z=0）
4. **上半圆**（Γ的虚部>0） = 感性负载（+jx，正电抗）
5. **下半圆**（Γ的虚部<0） = 容性负载（−jx，负电抗）
6. 从某点出发，**顺时针转** = 沿传输线**朝向发生器**方向移动（沿线远离负载、往信号源方向）
7. 从某点出发，**逆时针转** = 沿传输线**朝向负载**方向移动
8. **转一整圈360°** = 沿线移动 **λ/2**；**转180°** = 移动 **λ/4**
9. 圆图外圈通常印有"wavelengths toward generator"（顺时针方向刻度）和
   "wavelengths toward load"（逆时针方向刻度）两圈刻度尺，读出弧长对应的
   波长数即可，不需要每次都手算 2βd

**记忆口诀**：想象自己站在负载处往信号源方向"走"，圆图上的点就跟着
**顺时针**转——因为"往发生器方向走"英文是"toward generator"，可以联想
"generator"和"顺"都是"往前冲"的感觉来加深记忆；或者直接记住数学根源
（2.2.3节）：d增大 → e^(-j2βd) 相角变小 → 顺时针。

### 2.5.4 导纳圆图（Y-Smith Chart）
在做**并联**元件匹配时（并联电感、电容、短截线），用导纳 y=Y/Y0=1/z 计算
比阻抗方便得多（并联导纳可以直接相加，就像串联阻抗可以直接相加一样）。

关键结论：**把一个阻抗点在圆图上绕中心旋转180°，就得到它的导纳值所在
的位置**（因为 y=1/z 对应的Γ值正好是原来Γ值的相反数，即 -Γ，几何上就是
绕圆心转180°）。对应课程文件 `Colour Admittance on Impedance Smith Chart.pdf`
就是把阻抗网格和导纳网格叠加画在同一张图上（俗称"ZY圆图"），可以不用
旋转、直接切换着读，Module 3做匹配设计时会大量使用。

## 常见误区
- **分不清"朝向负载"和"朝向发生器"的圆图刻度方向** —— 建议用课程文件
  `Get Your Directions Right_r2.pdf`（Module 3附带但和圆图方向强相关）反复练习，
  并牢记2.2.3节的数学根源（d增大→相位变小→顺时针→朝发生器）。
- **用阻抗图直接读并联元件的导纳值**（必须先转换到导纳图，或利用"绕中心转180°"
  的倒易对称关系，见2.5.4节）。
- **把Z0当成"传输线消耗的电阻"**：无损线的Z0是纯实数但线本身不耗能，
  Z0只是"波的电压电流比"，不要和串联电阻R混淆。
- **把VSWR和反射系数Γ搞混**：VSWR是一个≥1的实数（标量），Γ是复数（有幅度也有相位）；
  两者可以互相换算（2.4.2节），但物理意义不同。
- **算Z_in时忘记tan(βd)里βd要用弧度**（或确认计算器角度模式），
  这是最容易丢分的低级错误。

## 例题讲解

**例题1：反射系数与VSWR计算**

一根 Z0=50Ω 的无损传输线，终端接 Z_L=100Ω 电阻，求 Γ_L 和 VSWR。

*解：*
```
Γ_L = (Z_L - Z0)/(Z_L + Z0) = (100-50)/(100+50) = 50/150 = 0.333（实数，相位0°）
VSWR = (1+|Γ_L|)/(1-|Γ_L|) = (1+0.333)/(1-0.333) = 1.333/0.667 ≈ 2.0
```
> 因为负载是纯电阻且大于Z0，反射系数为正实数（相位0°），在Smith圆图上落在实轴右侧。

**例题2：复数负载的反射系数**

Z0=50Ω，负载 Z_L = 30 + j40 Ω，求 Γ_L（直角坐标和极坐标形式）。

*解：*
```
Γ_L = (Z_L - Z0)/(Z_L + Z0) = (30+j40-50)/(30+j40+50) = (-20+j40)/(80+j40)
```
分子分母同乘分母共轭 (80-j40)：
```
分子: (-20+j40)(80-j40) = -1600+j800+j3200-j²1600 = -1600+j4000+1600 = j4000
分母: (80+j40)(80-j40) = 80²+40² = 6400+1600 = 8000
Γ_L = j4000/8000 = j0.5 = 0.5∠90°
```
> **考试技巧**：分母有虚数时，用"分子分母同乘分母的共轭复数"消去分母虚部，
> 这是复数除法的标准套路，Smith圆图题目里反复用到。

**例题3：输入阻抗计算（任意负载+任意线长）**

Z0=50Ω，负载 Z_L=25Ω（纯电阻），传输线电长度 βd=45°（即 d=λ/8），求输入阻抗 Z_in。

*解：*
```
Z_in = Z0·[Z_L + jZ0·tan(βd)] / [Z0 + jZ_L·tan(βd)]
tan(45°) = 1
Z_in = 50·[25 + j50×1] / [50 + j25×1] = 50·(25+j50)/(50+j25)
```
分子分母同乘 (50-j25)：
```
分子: 50×(25+j50)(50-j25) = 50×(1250-j625+j2500-j²1250) = 50×(2500+j1875)
分母: (50+j25)(50-j25) = 2500+625 = 3125
Z_in = 50×(2500+j1875)/3125 = 40+j30 Ω
```
> **考试技巧**：手算容易出错，建议用Smith圆图法验证——把 z_L=25/50=0.5 定位在圆图上，
> 沿等|Γ|圆顺时针转 2βd=90°，读出的归一化阻抗约为 0.8+j0.6，乘回Z0=50即得40+j30Ω，一致。

**例题4：Smith圆图旋转方向与位置**

在Smith圆图上，从 z=1+j1 出发，顺时针转90°，落在什么位置？对应移动了多少个λ？

*解：*
- 顺时针转 = 朝向发生器方向移动（沿传输线远离负载）
- 360° 对应 λ/2，所以 90° 对应 λ/8
- z=1+j1 对应 Γ = j1/(2+j1)，模 |Γ|=1/√5≈0.447，相角约63.4°
- 顺时针转90°后，新相角 = 63.4° - 90° = -26.6°（顺时针=相角减小）
- 在这个 |Γ|≈0.447 的圆上，相角-26.6°处对应的归一化阻抗约 z≈2.5-j0.7

> **考试技巧**：顺时针转动是相位减小的方向（因为 Γ(d)=Γ_L·e^(-j2βd)，d增大时指数相位变负）。

**例题5：短截线阻抗计算**

短路短截线长度为λ/8，特性阻抗Z0=50Ω，求其输入阻抗。

*解：*
```
βd = (2π/λ)×(λ/8) = 45°
Z_in = jZ0·tan(βd) = j×50×tan(45°) = j50 Ω
```
呈**感性**（正电抗），因为短路短截线长度 < λ/4 时恒为感性。

1. 一条50Ω无损线，终端接100Ω电阻，求Γ_L和VSWR。

```
Γ_L = (Z_L-Z0)/(Z_L+Z0) = (100-50)/(100+50) = 50/150 = 0.333（实数，相位0°）
VSWR = (1+0.333)/(1-0.333) = 1.333/0.667 ≈ 2.0
```

</details>

2. Z0=50Ω，负载Z_L=40-j30Ω，求Γ_L的直角坐标和极坐标形式。

<details><summary>点击查看答案</summary>

```
Γ_L = (40-j30-50)/(40-j30+50) = (-10-j30)/(90-j30)
```
分子分母同乘分母共轭 (90+j30)：
```
分子: (-10-j30)(90+j30) = -900-j300-j2700-j²900 = -900-j3000+900 = -j3000
分母: (90-j30)(90+j30) = 90²+30² = 9000
Γ_L = -j3000/9000 = -j0.333
```
**直角坐标**：Γ_L = 0 - j0.333
**极坐标**：|Γ_L| = 0.333，相角 = -90°，即 Γ_L = 0.333∠-90°

</details>

3. 在Smith圆图上，从z=1+j1出发，顺时针转90°，落在什么位置？对应移动了多少个λ？

<details><summary>点击查看答案</summary>

先把 z=1+j1 转成 Γ：
```
Γ = (z-1)/(z+1) = j1/(2+j1)，|Γ|=1/√5≈0.447，∠Γ=90°-26.57°=63.43°
```
顺时针（朝发生器方向）转90°，相角减少90°：
```
新相角 = 63.43°-90° = -26.57°
Γ_new = 0.447∠-26.57° ≈ 0.4-j0.2
```
转回阻抗：
```
z = (1+Γ_new)/(1-Γ_new) = (1.4-j0.2)/(0.6+j0.2) ≈ 2-j1
```
**落点约为 z=2-j1**（容性）。Smith圆图上360°对应λ/2，
所以旋转90°对应移动了 **λ/8**。

</details>

4. 短路短截线长度为λ/8，其输入阻抗是感性还是容性？数值是多少（用Z0表示）？

<details><summary>点击查看答案</summary>

```
βl = (2π/λ)×(λ/8) = 45°
Z_in = jZ0·tan(βl) = jZ0·tan45° = jZ0
```
**感性**，数值为 +jZ0（例如Z0=50Ω时为+j50Ω）。
短路短截线长度在0~λ/4之间恒为感性，这是因为tan(βl)在此区间恒为正。

</details>

5. Z0=75Ω，负载Z_L=150Ω，传输线电长度d=λ/4，求Z_in（提示：用λ/4变换公式验证）。

<details><summary>点击查看答案</summary>

λ/4变换器公式：
```
Z_in = Z0²/Z_L = 75²/150 = 5625/150 = 37.5 Ω
```
（可以用一般输入阻抗公式 Z_in=Z0·(Z_L+jZ0·tanβd)/(Z0+jZ_L·tanβd)，
代入βd=90°使tan→∞，化简后同样得到 Z_in=Z0²/Z_L，交叉验证一致。）

</details>
