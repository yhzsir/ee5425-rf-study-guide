## 🎓 老师的话：稳定性和振荡器是"一体两面"
这一章最容易让初学者困惑的地方是：前半章教你怎么"避免"自激振荡（稳定性判据），
后半章却教你怎么"故意制造"振荡（振荡器设计）。其实这恰恰揭示了RF工程的一个核心思想：
**同一套数学工具（K因子、Γin·ΓL的判据），既可以用来防止意外发生的事情，
也可以用来主动设计想要发生的事情**——放大器设计师害怕的"不稳定"，
正是振荡器设计师追求的"起振条件"。理解了这层关系，你会发现这一章
不是两个孤立的话题，而是同一个物理现象的两种应用方向。

在RF学习中特别有效，因为很多结论其实是可以从物理直觉推出来的。

## 6.1 稳定性判据
放大器若不稳定，会自激振荡（变成一个意外的振荡器！），因此设计放大器前必须检查稳定性。

**无条件稳定 vs 有条件稳定**：
- 无条件稳定（Unconditionally Stable）：对任何源/负载阻抗都不会振荡
- 有条件稳定（Conditionally Stable）：只在特定的Γs、ΓL范围内稳定，
  需要在Smith圆图上画"稳定圆"（Stability Circle）避开不稳定区域

**K因子判据（Rollett稳定因子）**：

```
K = (1 - |S11|² - |S22|² + |Δ|²) / (2|S12·S21|)
Δ = S11·S22 - S12·S21
```

**无条件稳定条件**：K > 1 **且** |Δ| < 1（两者缺一不可，有的教材用B1>0等价条件替代第二个）

## 6.2 稳定圆（Stability Circles）
- 输入稳定圆：在ΓL平面画出的圆，圆内/圆外对应S11'（输入反射系数）|S11'|=1的边界
- 输出稳定圆：在Γs平面画出的圆，对应S22'=1边界
- 圆心和半径公式（输出稳定圆为例）：
```
C_L = (S22 - Δ·S11*)* / (|S22|²-|Δ|²)
r_L = |S12·S21| / ||S22|²-|Δ|²|
```
判断稳定/不稳定区域：把原点(Γ=0，即Z0匹配点)代入S11'公式看是否<1，
若原点在稳定区，则圆外（若|S22|<1）为稳定区，反之圆内为稳定区。

## 6.3 振荡器设计原理
振荡器可视为"故意设计成不稳定"的放大器 + 正反馈：
- **负阻振荡器（Negative Resistance Method）**：设计一个单端口网络，
  在谐振频率处呈现负电阻（意味着它向外部提供能量而非消耗），
  与谐振电路（如晶体、LC谐振腔）配合形成起振条件：
  ```
  Γin·ΓT = 1  （起振条件：环路增益=1，相位=0）
  ```
  其中Γin是有源器件端看进去的反射系数，ΓT是谐振网络的反射系数。
- 常见振荡器拓扑：Colpitts、Hartley、Clapp（电容/电感分压反馈方式不同）
- 晶体振荡器（Crystal Oscillator）：用石英晶体的高Q谐振特性获得极高频率稳定度

## 6.4 起振条件与稳态条件
- **起振（Start-up）**：|Γin·ΓT| > 1（略大于1，保证扰动能被放大）
- **稳态振荡**：随振幅增大，有源器件进入饱和/非线性区，增益自动下降到
  |Γin·ΓT| = 1（自动稳幅机制）

## 常见误区
- 认为"稳定性差=坏事，一定要避免"——但振荡器设计恰恰是反过来利用不稳定性
- 只算K因子却忘记检查|Δ|<1这一条件

## 例题讲解

**例题1：K因子与稳定性判断**

已知晶体管在某频率下：S11=0.6∠-160°，S22=0.5∠-70°，S21=2.5∠80°，S12=0.05∠20°。
判断该晶体管在此频率下是否无条件稳定。

*解：*

先算 Δ = S11·S22 - S12·S21：
```
S11·S22 = 0.6×0.5∠(-160-70)° = 0.3∠-230° = 0.3∠130°
S12·S21 = 0.05×2.5∠(20+80)° = 0.125∠100°
```
转直角坐标相减：
```
0.3∠130° = 0.3×cos130°+j0.3×sin130° = -0.193+j0.230
0.125∠100° = 0.125×cos100°+j0.125×sin100° = -0.0217+j0.1231
Δ = (-0.193+j0.230) - (-0.0217+j0.1231) = -0.171+j0.107
|Δ| = √(0.171²+0.107²) = √(0.0292+0.0114) = √0.0406 ≈ 0.2016
```
K因子：
```
K = (1-|S11|²-|S22|²+|Δ|²)/(2|S12·S21|)
  = (1-0.36-0.25+0.0406)/(2×0.125)
  = 0.4306/0.25 ≈ 1.72
```
判断：K=1.72>1 **且** |Δ|=0.2016<1 → **两个条件都满足，无条件稳定**。

> **考试技巧**：K因子计算步骤繁琐，容易在Δ的相位加减或极坐标转直角坐标时出错，
> 建议按"先分别算S11·S22和S12·S21的极坐标 → 转直角坐标相减 → 求模" 的固定顺序做，
> 减少出错概率。K和|Δ|两个条件必须同时验证，只算K会漏掉部分"条件稳定"的情况。

**例题2：稳定圆半径与圆心（简化数值）**

沿用例题1的S参数，计算输出稳定圆（ΓL平面）的圆心C_L和半径r_L。

*解：*
```
|S22|² = 0.25，|Δ|² = 0.0406，|S22|²-|Δ|² = 0.2094
r_L = |S12·S21| / |0.2094| = 0.125/0.2094 ≈ 0.597
```
圆心 C_L = (S22 - Δ·S11*)* / (|S22|²-|Δ|²)，需要先算 Δ·S11*：
```
S11* = 0.6∠160°（共轭：模不变，相位取反）
Δ·S11* = 0.2016∠(Δ相位)×0.6∠160°
```
Δ的相位：Δ=-0.171+j0.107，位于第二象限，
```
θ_Δ = 180° - arctan(0.107/0.171) = 180°-32.05° = 147.95°
Δ·S11* = 0.2016×0.6 ∠(147.95°+160°) = 0.121∠307.95°
       = 0.121×cos307.95° + j0.121×sin307.95° ≈ 0.0744 - j0.0954
S22 - Δ·S11* = (0.5cos(-70°)+j0.5sin(-70°)) - (0.0744-j0.0954)
             = (0.171-j0.470) - (0.0744-j0.0954) = 0.0966-j0.3746
共轭（取*）: 0.0966+j0.3746
C_L = (0.0966+j0.3746)/0.2094 ≈ 0.461+j1.789
```
> **考试技巧**：这类题手算量很大，实际考试常只要求代公式列出步骤、
> 或直接告知S参数后只让你判断"原点在圆内还是圆外"来定稳定/不稳定区，
> 不一定要求算出精确的圆心/半径数值——审题时注意题目问的是"判断"还是"求出"。

**例题3：负阻振荡器起振条件的数值判断**

某负阻振荡器中，有源器件端反射系数 Γin = 1.2∠30°，谐振网络反射系数 ΓT = 0.9∠-30°。
判断是否满足起振条件。

*解：*
```
Γin·ΓT = 1.2×0.9 ∠(30°-30°) = 1.08∠0°
```
- 幅度 |Γin·ΓT| = 1.08 > 1 ✓（满足起振的幅度条件，扰动能被放大）
- 相位 = 0° ✓（满足相位条件，正反馈）

**结论：满足起振条件**，电路会自激振荡。随振幅增大，有源器件进入饱和，
|Γin|会自动下降，直到 |Γin·ΓT| 降回1（稳态振荡条件），相位仍保持0°。

> **物理理解**：起振要求环路增益略大于1（留有余量克服初始噪声很小的扰动），
> 稳态时降为恰好等于1（能量注入=损耗，幅度不再增长）——这和运放正反馈振荡器
> 的巴克豪森准则（Barkhausen Criterion）思路完全一致。
