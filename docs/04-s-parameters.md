# Module 4 — S-Parameters

**对应文件**：`EE5425_CityUHK-DG_4_FoRCE_SP_2026A_Sr1.pdf`

## 学习目标
理解为什么高频电路要用S参数（散射参数）而不是低频常用的Z/Y/H参数来描述网络。

## 4.1 为什么用S参数
- 高频下很难实现真正的"开路"或"短路"边界条件来测量Z/Y参数（寄生效应、
  开路会辐射、短路有引线电感），而且晶体管在高频短路/开路下容易自激振荡、损坏
- S参数用**入射波和反射波**（而非电压电流）描述网络，测量时用匹配负载（通常50Ω）
  终端即可，不需要真正开短路

## 4.2 两端口S参数定义

```
b1 = S11·a1 + S12·a2
b2 = S21·a1 + S22·a2
```

其中 a1,a2 为端口1、2的**入射波**（归一化功率波），b1,b2为**反射/透射波**。

| 参数 | 物理意义 | 测量条件 |
|---|---|---|
| S11 | 输入端反射系数 | 输出端接匹配负载(a2=0) |
| S21 | 正向传输增益 | 输出端接匹配负载(a2=0) |
| S22 | 输出端反射系数 | 输入端接匹配负载(a1=0) |
| S12 | 反向隔离（反向传输） | 输入端接匹配负载(a1=0) |

- |S21|² = 正向功率增益（dB形式：Gain(dB) = 20log|S21|）
- |S11|² = 输入端反射功率比例，回波损耗 RL(dB) = -20log|S11|

## 4.3 S参数与其他参数的转换
S参数可与Z、Y参数互相转换（考试可能考公式代入），核心记住：
- S参数依赖参考阻抗Z0（通常50Ω），换参考阻抗S参数会变
- 无耗、互易网络满足 |S11|²+|S21|²=1（功率守恒），且 S12=S21

## 4.4 常见应用
- 用网络分析仪（Module 7会讲）直接测量器件的S参数
- 晶体管数据手册中给出的S参数是放大器设计（Module 5）的**输入数据**
- 级联网络可用**转移散射参数 T-parameter** 或 **ABCD参数**转换后相乘（S参数本身不能直接相乘）

## 常见误区
- 认为S参数和阻抗无关——实际上S参数是相对于某个参考阻抗Z0定义的
- 混淆增益的dB表达式：电压/电流比用20log，功率比用10log；S21是波的比值（类似电压比），
  所以功率增益是20log|S21|，不是10log|S21|
