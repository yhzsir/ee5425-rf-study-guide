## 5.1 小信号放大器设计流程
1. **选晶体管**，获取其S参数（在工作频点、工作偏置下）
2. **稳定性检查**（见Module 6，K因子），确保不会自激振荡
3. **画增益圆（Gain Circles）**：在Smith圆图上画出定增益轨迹，
   帮助在增益与匹配复杂度之间取舍
4. **设计输入/输出匹配网络**（用Module 3的方法），使源阻抗/负载阻抗
   变换到晶体管所需的最佳阻抗
5. **设计偏置网络（Bias Network）**：给晶体管提供合适的直流工作点，
   同时RF信号不能泄漏进直流电源（用RF choke电感和去耦电容隔离）

## 5.2 功率增益的几种定义（重点公式，考试常考）
- **Transducer Gain G_T**：实际负载得到的功率 / 信号源能提供的最大功率（最常用，
  综合考虑了输入失配和输出失配）
- **Power Gain G_P**：负载得到的功率 / 网络输入端实际吸收的功率（不考虑输入失配）
- **Available Gain G_A**：网络能提供的最大功率 / 信号源能提供的最大功率

```
G_T = [(1-|Γs|²)/|1-Γin·Γs|²] · |S21|² · [(1-|ΓL|²)/|1-S22·ΓL|²]
```
（Γs为源反射系数，ΓL为负载反射系数，Γin为放大器输入端看进去的反射系数）

**单向化假设（Unilateral，S12≈0）** 下公式简化为：
```
G_T,U = Gs · G0 · GL
Gs = (1-|Γs|²)/|1-S11Γs|²,  G0=|S21|²,  GL=(1-|ΓL|²)/|1-S22ΓL|²
```
这是初学者最先掌握的简化设计方法：分别做输入、输出的"共轭匹配"，
Γs=S11*，ΓL=S22*，可得最大单向功率增益 G_T,U,max。

## 5.3 低噪声放大器（LNA）设计
- 目标：在满足一定增益的前提下**最小化噪声系数NF**
- 噪声系数圆（Noise Figure Circles）：在Smith圆图上画出等NF轨迹，
  与增益圆叠加，在两者之间找折中点（LNA设计通常不能同时兼顾最小噪声匹配
  和最大增益匹配，因为最佳噪声源阻抗Γ_opt通常≠共轭匹配点S11*）
- Friis公式（级联噪声系数，前级增益越高，后级噪声贡献越小）：
```
F_total = F1 + (F2-1)/G1 + (F3-1)/(G1·G2) + ...
```
—— 这说明**第一级LNA的噪声系数和增益直接决定整个接收链的噪声性能**，
这也是为什么LNA要尽量靠近天线放置。

## 5.4 偏置网络设计要点
- RF Choke（高值电感）：在直流通路上，对RF信号呈现高阻抗，隔离RF不进电源
- 旁路电容（Bypass/Decoupling Capacitor）：为RF信号提供交流接地路径
- 常见拓扑：有源偏置（用电流镜/反馈稳定工作点）vs 无源偏置（电阻分压，简单但受温漂影响大）

## 5.5 微带线相关（放大器物理实现）
放大器的匹配网络在实际PCB/MMIC上常用微带线（microstrip）实现短截线/变换线段，
需要用到：
- 特性阻抗计算（依赖 W/h, ε_r）
- 有效介电常数 ε_eff 和微带波长 λ_g
- 微带损耗（导体损耗、介质损耗、辐射损耗）

## 5.6 功率放大器（Power Amplifier, PA）简介（进阶模块8内容）
- 与小信号放大器不同，PA工作在大信号状态，需要考虑：
  - 效率（Efficiency）：η = P_out/P_DC，功率附加效率 PAE = (P_out-P_in)/P_DC
  - 工作类别（Class A/B/AB/C）：导通角不同，效率与线性度的折中
  - 1dB压缩点(P1dB)、三阶交调点(IP3)——非线性失真指标
  - 负载牵引（Load-pull）技术：实验寻找最佳负载阻抗（不是简单共轭匹配）

## 常见误区
- 把"共轭匹配（Conjugate Match）"和"最小噪声匹配"混为一谈——二者在LNA设计中通常不重合
- 忽略偏置网络对RF性能的影响，认为偏置只是"直流的事"

## 例题讲解

**例题1：最大单向功率增益计算**

已知某晶体管 S11=0.3∠140°, S22=0.4∠-60°, S21=3∠60°, S12≈0（单向化假设），
求最大单向功率增益(dB)。

*解：*
单向化下，Gs、GL 分别在 Γs=S11*、ΓL=S22* 时取最大值（共轭匹配）：
```
Gs,max = 1/(1-|S11|²) = 1/(1-0.3²) = 1/(1-0.09) = 1/0.91 ≈ 1.099
G0 = |S21|² = 3² = 9
GL,max = 1/(1-|S22|²) = 1/(1-0.4²) = 1/(1-0.16) = 1/0.84 ≈ 1.190
```
```
G_T,U,max = Gs,max × G0 × GL,max = 1.099 × 9 × 1.190 ≈ 11.77
```
转dB：
```
G_T,U,max(dB) = 10log(11.77) ≈ 10.71 dB
```
> **考试技巧**：单向化最大增益公式中，Gs和GL用**功率比**直接相乘，
> 最后统一转dB用10log（因为这里已经是"功率增益"而非"电压/波的幅度比"，
> 不要和S21本身的20log弄混——S21平方后本身就是功率增益 |S21|²）。

**例题2：Friis公式级联噪声系数**

某接收链路三级级联：
- 第一级（LNA）：增益 G1=15dB，噪声系数 F1=1.5dB
- 第二级（混频器）：增益 G2=-6dB（有损耗），噪声系数 F2=6dB
- 第三级（中频放大器）：增益 G3=20dB，噪声系数 F3=3dB

求整个链路的总噪声系数（dB）。

*解：*
先把dB转换成线性值：
```
G1=15dB → 10^(1.5)=31.6，F1=1.5dB → 10^(0.15)=1.413
G2=-6dB → 10^(-0.6)=0.251，F2=6dB → 10^(0.6)=3.981
F3=3dB → 10^(0.3)=1.995
```
Friis公式：
```
F_total = F1 + (F2-1)/G1 + (F3-1)/(G1·G2)
        = 1.413 + (3.981-1)/31.6 + (1.995-1)/(31.6×0.251)
        = 1.413 + 2.981/31.6 + 0.995/7.93
        = 1.413 + 0.0943 + 0.1254
        = 1.633
```
转回dB：
```
F_total(dB) = 10log(1.633) ≈ 2.13 dB
```
> **核心结论**：总噪声系数(2.13dB)非常接近第一级LNA的噪声系数(1.5dB)，
> 后两级的噪声贡献因为除以了第一级的高增益(31.6倍)而被大幅"稀释"——
> 这正是Friis公式最重要的工程意义：**第一级增益越高，后级噪声影响越小**，
> 所以LNA要尽量靠近天线放置，且要有足够增益。

**例题3：偏置网络设计判断**

某RF放大器工作频率2GHz，直流偏置需要提供漏极电压。若在偏置支路上使用一个10nH的电感作为
RF choke，求它在2GHz时呈现的阻抗，判断是否"足够大"以隔离RF信号（一般认为阻抗需 >>50Ω，
如大于500Ω才算有效隔离）。

*解：*
```
X_L = ωL = 2π×2×10⁹×10×10⁻⁹ ≈ 125.7 Ω
```
125.7Ω 虽然比50Ω大，但按">>50Ω(建议>500Ω)"的经验标准还**不够大**，
RF信号仍会有一部分泄漏进直流偏置电路，实际设计中应选用更大电感（如47nH或100nH），
或改用多级LC滤波结构（choke+旁路电容级联）进一步提高隔离度。

> **考试技巧**：这类题目考察"数量级判断"，記住 X_L=ωL 中频率越高、电感越大，
> 隔离效果越好，但过大的电感在高频下容易出现自谐振（寄生电容效应），需要折中选择。

**2.** 解释为什么LNA设计中最佳噪声匹配点和最大增益匹配点通常不是同一个Γs。

<details><summary>点击查看答案</summary>

最大增益匹配要求Γs = S11*（与输入反射系数共轭匹配，让功率完全传输进器件）；
但晶体管的噪声性能由其内部噪声机制（沟道热噪声、感应栅极噪声等）决定，
存在一个与S11无关的最佳噪声源阻抗Γ_opt，这个点是由噪声参数
（Fmin, Γ_opt, Rn）决定的，一般并不等于S11*。因此LNA设计需要在
"增益圆"和"噪声系数圆"两组等值线中找折中点：既要噪声系数足够低，
又要有足够的增益，很难同时达到各自的最优点。

</details>

**3.** 画出一个基本的RF放大器偏置网络示意图，标出RF choke和旁路电容位置。

<details><summary>点击查看答案</summary>

典型结构（以漏极偏置为例）：直流电源 → RF Choke电感（串联在直流电源
和晶体管漏极之间，对RF呈高阻抗，阻止RF信号泄漏进电源）→ 晶体管漏极。
同时在RF choke和电源之间接一个旁路电容（Bypass Capacitor，对地），
为可能窜入的RF信号提供低阻抗接地通路。RF信号通路上则用隔直电容
（DC blocking capacitor）串联，防止直流偏置窜入信号源/负载。
（示意：DC电源 —RF Choke— 漏极 —隔直电容— RF输出，choke与漏极节点处
并联旁路电容到地）

</details>

**4.** 两级级联：G1=20dB, F1=2dB；G2=10dB, F2=8dB，求总噪声系数(dB)，并说明若把两级顺序调换，总噪声系数会如何变化。

<details><summary>点击查看答案</summary>

先转成线性值：F1=10^(2/10)=1.585，G1=10^(20/10)=100；F2=10^(8/10)=6.31，G2=10^(10/10)=10

**原顺序（低噪声级在前）**：

```
F_total = F1 + (F2-1)/G1 = 1.585 + (6.31-1)/100 = 1.585+0.053 ≈ 1.638
NF_total = 10log(1.638) ≈ 2.14 dB
```

**顺序调换（高噪声级在前）**：

```
F_total' = F2 + (F1-1)/G2 = 6.31 + (1.585-1)/10 = 6.31+0.0585 ≈ 6.37
NF_total' = 10log(6.37) ≈ 8.04 dB
```

**结论**：顺序调换后总噪声系数从2.14dB恶化到8.04dB，
证明了Friis公式的核心工程意义——**噪声系数最低、增益最高的一级必须放在最前面**，
这也是为什么LNA要紧靠天线放置。

</details>
