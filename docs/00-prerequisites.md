# 0. 课前准备：你需要具备的基础知识

RF电路的核心难点不是"新知识"，而是**用复数和相位的语言重新理解电路**。在正式进入课程前，请确保掌握：

## 0.1 复数与相量（Phasor）
- 复数的直角坐标 (a+jb) 与极坐标 (r∠θ) 互换
- 欧拉公式：e^(jθ) = cosθ + j·sinθ
- 正弦稳态电路中，电压/电流用相量表示：v(t)=V₀cos(ωt+φ) ↔ V = V₀∠φ
- **为什么RF要用复数**：因为反射系数、阻抗、S参数全部是复数（有幅度和相位）

## 0.2 电路基础回顾
- 欧姆定律的相量形式：V = IZ
- 阻抗 Z = R + jX（电阻+电抗），导纳 Y = G + jB（电导+电纳）
- 电感阻抗 Z_L = jωL，电容阻抗 Z_C = 1/(jωC) = -j/(ωC)
- 串并联阻抗合成、戴维南/诺顿等效电路

## 0.3 电磁波与传输线的直觉
- 为什么"低频电路"可以忽略导线长度，而"高频电路"不行？
  - 判据：当导线物理长度 l 与信号波长 λ 相比不可忽略（一般 l > λ/20~λ/10）时，
    电压/电流沿导线的传播时延不能再忽略，必须用**分布参数**（传输线）模型，
    不能再用集总参数（一个电阻/电容代表整个器件）。
  - RF频段（MHz~GHz），波长在厘米到米级，电路板尺寸往往接近波长量级 → 必须用传输线理论。
- 波长与频率关系：λ = v/f，真空中 v=c=3×10⁸ m/s；介质中 v = c/√ε_r
