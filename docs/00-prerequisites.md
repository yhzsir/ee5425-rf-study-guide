# 0. 课前准备：你需要具备的基础知识

RF电路的核心难点不是"新知识"，而是**用复数和相位的语言重新理解电路**。在正式进入课程前，请确保掌握：

## 0.1 复数与相量（Phasor）
- 复数的直角坐标 (a+jb) 与极坐标 (r∠θ) 互换
- 欧拉公式：e^(jθ) = cosθ + j·sinθ
- 正弦稳态电路中，电压/电流用相量表示：v(t)=V₀cos(ωt+φ) ↔ V = V₀∠φ
- **为什么RF要用复数**：因为反射系数、阻抗、S参数全部是复数（有幅度和相位）

## 0.2 电路基础回顾
- 欧姆定律的相量形式：V = IZ
- 阻抗 Z = R + jX（电阻+电抗），导纳 Y = G + jB（电导+电纳）
- 电感阻抗 Z_L = jωL，电容阻抗 Z_C = 1/(jωC) = -j/(ωC)
- 串并联阻抗合成、戴维南/诺顿等效电路

## 0.3 电磁波与传输线的直觉
- 为什么"低频电路"可以忽略导线长度，而"高频电路"不行？
  - 判据：当导线物理长度 l 与信号波长 λ 相比不可忽略（一般 l > λ/20~λ/10）时，
    电压/电流沿导线的传播时延不能再忽略，必须用**分布参数**（传输线）模型，
    不能再用集总参数（一个电阻/电容代表整个器件）。
  - RF频段（MHz~GHz），波长在厘米到米级，电路板尺寸往往接近波长量级 → 必须用传输线理论。
- 波长与频率关系：λ = v/f，真空中 v=c=3×10⁸ m/s；介质中 v = c/√ε_r

## 0.4 例题讲解

**例题1：直角坐标 ↔ 极坐标互换**

已知复数 Z = 3 + j4，求其极坐标形式。

*解：*
- 模：|Z| = √(3² + 4²) = √25 = 5
- 相角：θ = arctan(4/3) = 53.13°
- 所以 Z = 5∠53.13°

反过来，若已知 Z = 10∠-30°，求直角坐标：
- 实部：Re(Z) = 10·cos(-30°) = 10×0.866 = 8.66
- 虚部：Im(Z) = 10·sin(-30°) = 10×(-0.5) = -5
- 所以 Z = 8.66 - j5

> **考试技巧**：极坐标转直角坐标用 cos/sin，直角转极坐标用勾股定理+arctan，
> 一定要注意 arctan 的象限问题（实部为负时，角度要加减180°）。

**例题2：阻抗串并联计算（相量法）**

工作频率 f = 1GHz，电感 L = 5nH，电容 C = 2pF，求两者串联后的总阻抗（在此频率下）。

*解：*
- ω = 2πf = 2π×10⁹ ≈ 6.283×10⁹ rad/s
- Z_L = jωL = j×6.283×10⁹×5×10⁻⁹ = j31.4 Ω
- Z_C = 1/(jωC) = -j/(6.283×10⁹×2×10⁻¹²) = -j79.6 Ω
- 串联总阻抗：Z = Z_L + Z_C = j31.4 - j79.6 = -j48.2 Ω（呈容性）

> **考试技巧**：先算 ωL 和 1/(ωC) 的数值，再确定正负号（电感+j，电容-j），
> 最后直接相加，不要把符号搞反。

**例题3：波长计算**

信号频率 f = 2.4GHz（Wi-Fi频段），求其在自由空间和在 ε_r=4.5 的介质中的波长。

*解：*
- 自由空间：λ₀ = c/f = (3×10⁸)/(2.4×10⁹) = 0.125m = 12.5cm
- 介质中：v = c/√ε_r = (3×10⁸)/√4.5 ≈ 1.414×10⁸ m/s
  λ = v/f = (1.414×10⁸)/(2.4×10⁹) ≈ 5.89cm

> **物理意义**：介质中波长变短（因为电磁波在介质中传播变慢），
> 这也是为什么微带线上的元件尺寸可以比自由空间波长小很多——这是Module 2/5的基础。
