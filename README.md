## 🎓 如何用好这个网站自学（写给独立学习者）

这个网站的设计目标是：**即使完全没有老师带、没有同学讨论，你一个人也能靠它学完这门课**。
为此每个模块页面都包含五个部分，建议按顺序使用：

1. **📺 推荐视频** —— 先看视频建立直觉印象，不用一次看懂，看个大概即可
2. **🎓 老师的话** —— 每个模块开头都有一段"教学建议"，说明这一章在整门课里的
   位置、常见的学习误区、以及自学时应该重点检验自己哪方面的理解，请认真读完
3. **核心知识点 + 公式** —— 系统的文字讲解，建议对照课程原始PDF一起看
4. **例题讲解** —— 每道例题**先自己动手算，再看解答**，这是这门课最有效的学习方式
5. **自测题** —— 学完一节后，合上页面，独立完成，做不出来再回头查对应小节

**遇到卡壳怎么办**：
- 先检查是不是前置知识没打牢（比如学Module 3卡壳，很可能是Module 2的Smith圆图
  操作还不熟练，回去补Module 2比硬啃Module 3更有效）
- 各模块顶部都标注了"对应课程文件"，可以对照老师原始PDF的Worksheet/Tutorial
  加练，这些题目和考试题型最接近
