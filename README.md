# EE5425 零基础学习指南
### Fundamentals of Radio Frequency (RF) Circuit Engineering — City University of Hong Kong

> 本指南基于城大 EE5425 官方课程大纲（7个模块的讲义/Worksheet/Tutorial PDF）整理，
> 结合公开的射频工程知识，面向**完全没有RF背景**的同学，从数学/电路基础一路讲到
> S参数、放大器设计、振荡器与RF测量。建议按顺序学习，每个模块都配有"学习目标 +
> 核心知识点 + 公式 + 常见误区 + 对应课程文件 + 自测题"。
